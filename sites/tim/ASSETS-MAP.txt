Победа

На мобильных ширинах 360–430 px onboarding собирается из наших готовых изображений + HTML/CSS и визуально повторяет утверждённые макеты.

1. Общий принцип сборки

Референсные фоновые сцены имеют размер 941 × 1672 px. Это наш базовый artboard.

Не надо обрезать их через агрессивный background-size: cover, потому что на современных длинных телефонах можно потерять руки Тима или правую деревянную табличку.

Лучший принцип:

.tim-screen {
    position: relative;
    width: min(100vw, 430px);
    min-height: 100dvh;
    margin: 0 auto;
    overflow: hidden;

    background:
        linear-gradient(#8fd8ff 0%, #f7ddb1 70%, #f6d59d 100%);
}

.tim-scene {
    position: absolute;
    left: 0;
    top: 0;
    width: 100%;
    height: auto;
    z-index: 0;
}

То есть картинку всегда сохраняем полностью по ширине. Если экран телефона длиннее изображения — нижнюю часть продолжаем спокойным песочным фоном.

Все координаты ниже считаются относительно исходного artboard 941×1672.

2. Z-index

Строго:

0   — фоновая сцена с Тимом
10  — деревянная надпись / декоративные элементы
20  — формы и карточки
30  — интерактивные элементы формы
40  — speech-bubble Тима
50  — header / Войти
60  — ошибки / системные сообщения

Исключение — там, где рука Тима должна визуально оказаться перед формой.

Но поскольку Тим уже является частью фоновой картинки, этот эффект создаём не z-index'ом руки, а точным совпадением верхней границы формы с рукой.

Ничего отдельно у Тима вырезать не надо.
