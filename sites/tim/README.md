# `/tim/` — онбординг «Островёнок Тим»

> **Канон порядка экранов** — ниже «Текущий путь (факт кода)».  
> Желаемый путь Макса (вариант В) — ещё не зафиксирован; сначала выжимаем факт.

## URL

- `/tim/` (редирект `/tim` → `/tim/`)
- Smoke: `?force=1` — не уводит в ЛК даже при `savedUser`
- Превью экрана: `?force=1&screen=4` (также `1`…`9`, `login`, `fio`, `pwa`)
- Пасхалка сборки: `.tim-build` справа внизу экрана (= `.app-version` в корневом `index.html`)

## Ассеты

- Ранние экраны 1–3 + confirm: `assets/v2/` (lite JPEG → WebP)
- Аккаунт / соцсети: `scene_account_*` в `assets/v2/`
- Старый fin: `assets/fin/` (часть экранов / запас)
- Мастерская Компаса: `Images/Тим/` (inbox → candidates → в `assets/`, не в код напрямую)

## Текущий путь (факт кода, `tim-fsm.js`)

### Старт

| Условие | Куда |
|--------|------|
| Есть `savedUser`, **нет** `force=1` | Редирект в ЛК `/index.html` |
| Есть `savedUser` + `force=1` | Tim с подставленным user (имя/город), старт с экрана 1 |
| Нет user | Старт с экрана **1** |

### Основной поток (новый человек + мечты)

```
1 Знакомство
  → имя + город → «Познакомиться»
2 Видео
  → заглушка / video → «к Мечтам!»
3 Витрина мечт
  → одна мечта за раз, «+», удаление
  → «Готово!» (при клавиатуре) = добавить черновик как «+» и показать отправку
  → «Отправить N мечт Тиму»
4 Аккаунт (обложка scene_account)
  → имя ✓, город ✓, фамилия+отчество (необяз.), телефон (код страны), пароль
  → «Зарегистрироваться» → POST /register + login
5 Соцсети (та же обложка)
  → MAX / TG / VK / WA / Mail
  → MAX и TG: юзернейм и телефон — два поля; галочка подтверждает → иконка цветная
  → «Далее» → PATCH contacts (tg/vk) + сохранить мечты
→ ЛК /index.html
```

Экран **9 (успех)** из happy-path **убран**. С витрины (3) «Отправить Тиму» **не** ведёт сразу в ЛК — только 4→5, затем `saveDreams` → ЛК.

### Ветки

| Откуда | Куда | Когда |
|--------|------|--------|
| 3 → 4 | «Отправить Тиму» всегда (`pendingDreamSave`), дальше 4 → 5 |
| 5 → ЛК | После «Далее», если были отложенные мечты → `saveDreams` → `/index.html` |
| 5 → `pwa` или 3 | «Далее» **без** pending мечт → `afterContacts()` |
| `pwa` → 3 | Установить / браузер / позже |
| 4 → 5 | Успешная регистрация всегда |
| Header «Войти» | экран `login` → при успехе сразу ЛК |
| `?screen=` | Прямой прыжок (отладка) |

### Экраны, которые ещё есть в коде, но не в основном happy-path

| id | Что | Заметка |
|----|-----|---------|
| `fio` | Фамилия + отчество отдельно | Запас; поля уже на экране 4 |
| `pwa` / было 6 | PWA-оффер | После соцсетей, если нет pending-мечт и PWA ещё не предлагали |
| 7 | Снова витрина | Legacy |
| 8 | Сразу переключает на 3 | Legacy «сверка» |

### API по пути

- `POST /register`, `POST /login`
- `PATCH /users/me` — telegram / vk
- `POST /dreams` — после соцсетей (или сразу с 3, если user уже есть)
- Черновик каналов: `localStorage` `tim_contact_channels`; отчество: `tim_patronymic`

## Layout

- Artboard канон **1080×2400** (экраны 1–5, login) или legacy **941×1672**
- Масштаб **только по ширине** stage (max 430px); вертикаль — лёгкий скролл
- Фон `body`: небо `#6eb8e8` (не песок)
- Карточки **без** белой/стеклянной подложки
- Координаты: `CARD_LAYOUT` в `js/assets.js`
