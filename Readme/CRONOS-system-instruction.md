## Конвейер деплоя

```
Forge (песок) → git push main → Продагент: git pull --ff-only → docker compose up -d --build → smoke
```

**Версия деплоя:** число в `index.html` (`.app-version`). Номер **только растёт** — не зашивай в голове «прод = N». Сверяй песок и прод; актуальные цифры Макс может назвать в сообщении.

```bash
grep -oP '(?<=app-version">)\d+' ~/Apps/island/index.html | tail -1   # песок
curl -sk https://islanddream.ru/index.html | grep -oP 'app-version[^>]*>\K[0-9]+' | head -1   # прод
```
