# Postmortem: Bloom digest 2026-09-02 02:10 MSK

Дата расследования: 2026-09-02. **Production не менялся** — только чтение кода/логов/БД.

## Deployed code (факт)

| Компонент | Значение |
|-----------|----------|
| Git commit | `1ddacbd` (v324) |
| Cron | `10 23 * * *` → `bloom/send_digest.py --send` (**без** `--date`, **без** `TZ=`) |
| Сервер | `UTC` (`timedatectl`: `Etc/UTC`) |
| Лог | `logs/bloom_digest.log` — единственная запись, модификация `Sep 1 23:10 UTC` |

Цепочка вызовов:

```
cron 23:10 UTC
  → bloom/send_digest.py --send
    → report_date = datetime.now(Europe/Moscow).date()   # строка 76, commit 1ddacbd
    → build_snapshot(cur, report_date)
      → _fetch_today_steps(cur, report_date)             # deadline = report_date
      → _fetch_reported_ids(cur, report_date, ...)
      → avg_steps_pct = mean(per-user pct)               # строки 426-427
    → format_telegram_evening_digest(snapshot)
      → cycle_day = report_date.day                       # «День N»
      → team_pct = today.avg_steps_pct
```

## Root cause

**Двойная ошибка даты + неверный групповой %:**

1. **Cron в UTC, не MSK:** `23:10 UTC` = **`02:10 MSK` следующего календарного дня**.
2. **`now(MSK).date()` в момент запуска** → `2026-09-02`, а не `2026-09-01`.
3. Digest закрыл **2 сентября** (день 2), хотя по смыслу вечернего отчёта нужно было **1 сентября**.
4. **11.4%** = среднее персональных % за 2 сентября: только Света 4/5=80%, остальные 0% → `80/7≈11.4`.  
   Правильно для 1 сентября: **9/22 = 40.9%** (`SUM(done)/SUM(total)`).
