# Bootstrap — только для старта нового чата CRONOS

> **Разовая процедура.** Делается **один раз**, когда открываешь **новый** чат (старый уперся в токены или начинаешь с нуля).  
> **System Instructions** — постоянные; **bundle** — разовая «загрузка памяти» в первое сообщение.

---

## Два слоя (не путать)

| Слой | Где | Когда | Что внутри |
|------|-----|-------|------------|
| **System Instructions** | Настройки чата в AI Studio | Один раз при создании промпта; одни и те же для всех сессий с этим промптом | Личность, топология, правила — [CRONOS-system-instruction.md](CRONOS-system-instruction.md) |
| **Bootstrap** | Первое сообщение нового чата | **Один раз** на чат | Прикреплённый bundle + короткий текст со статусом «на сегодня» |

Пока **тот же чат** живой — bundle **не** прикрепляй снова: Кронос помнит из истории сообщений.

---

## Порядок (новый чат)

### 0. Собери bundle (если давно не обновлял)

```bash
cd ~/Apps/island
bash scripts/build_cronos_upload_bundle.sh
```

### 1. System Instructions

Вставь блок из [CRONOS-system-instruction.md](CRONOS-system-instruction.md) (если промпт новый — или оставь уже сохранённый).

### 2. Первое сообщение — один раз

1. **«+»** → прикрепи `Readme/CRONOS-upload-bundle.md`
2. Вставь текст и отправь:

```
Кронос, привет. Новый чат, продолжаем ОСТРОВ.

Я — Макс. В приложении — upload-bundle (прочитай один раз сейчас).

Статус на сегодня:
- Прод: версия ЛК ___
- Песок: версия ЛК ___
- (если песок > прод — ждёт KiP)

Подтверди контекст в 2–3 предложениях. Дальше работаем из этого чата, без повторного bundle.
```

Подставь версии из `grep app-version` / islanddream.ru.

### 3. Дальше в том же чате

Обычные сообщения. Bundle снова — только если:
- открыл **новый** чат;
- было **крупное** изменение (ADR, деплой) — тогда: «обновил bundle, перечитай» + новое вложение.

---

## Если bundle не влезает

Минимум: `CRONOS-handoff.md` + `DECISIONS.md`. Текст:

```
Кронос, bootstrap: handoff + ADR в приложении. System Instructions на месте. Подтверди контекст.
```

---

## Чего не делать

- Не просить Кроноса «каждый раз читать Readme/…» — файлов на диске у него нет.
- Не дублировать bootstrap-процедуру в System Instructions — там только постоянные правила.
