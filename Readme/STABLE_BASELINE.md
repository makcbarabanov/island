### Как устроен номер и кэш PWA

Источник: `main.py`, функция `_app_frontend_version`, и `GET /sw.js` в коммите `b0b6c43`.

- Файл `sw.js` в git содержит заготовку `island-pwa-v__ISLAND_APP_VERSION__`.
- При запросе `/sw.js` сервер подставляет цифры из `.app-version`. Для прода 413 браузер получает кэш `island-pwa-v413`.
- `index.html` отдаётся с `Cache-Control: no-cache`. В кэш service worker на установке кладётся манифест, не HTML.
