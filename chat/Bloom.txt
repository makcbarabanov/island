- Канон подсайтов Острова в доке: **`web-app/sites/<name>/`** → FastAPI mount → Docker (как `/breakfast/`). См. `web-app/Readme/sites-architecture.md`.

| Исторический `chat.txt` | в git как **data/** (или отдельный архивный файл с README), не «только на проде» |
| Сборка | `build-stat.py` в CI или cron на проде **после** pull, пишет `stat.html` из шаблона + JSON |

## 4. Сайт статистики — что расширять (v1 метрики)

Согласен с Кроносом: **не считать на лету** по миллионам строк. Раз в сутки (03:00 MSK?) job:
1. Читает БД + при необходимости дополняет legacy из `_educ_*`
2. Пишет **`marathon_snapshot.json`** (или строку в `_educ_daily_snapshots`)
3. `stat.html` / фронт только рисует JSON

**Метрики v1 (предложение):**
- Марафонов всего / участников уникальных / человеко-марафонов
- Средний % выполнения шагов за день / за марафон (из ЛК)
- % сдавших отчёт (📋/✈️ или `_educ_reports_daily`)
- Топ «тяжёлых» привычек (низкий % ✓ по названию шага, min N участников)
- Топ «лёгких» (высокий %)
- Streak: сколько дней подряд с отчётом / с 100% шагов
- Графики: участники по месяцам, средний % по дням 1–21

**Личная страница:** `/marathon/stat/?user=…` или tg-id — только свои цифры + место в группе (если не страшно по приватности).
